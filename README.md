# ProgWeb_Eva2

## Instalacion

Instalar dependencias y ejecutar proyecto:
bash npm install
bash npx nodemon app.js

## Base de datos
Importar el script SQL incluido para crear la base de datos y las tablas:
- comentarios_blog
- proveedores_logistica

## Endpoints

### comentarios
- POST /comentarios
- GET /comentarios
- GET /comentarios/:id
- PUT /comentarios/:id
- DELETE /comentarios/:id

### proveedores
- POST /proveedores
- GET /proveedores
- GET /proveedores/:id
- PUT /proveedores/:id
- DELETE /proveedores/:id

## Pruebas
Las pruebas fueron realizadas en Postman.

Se incluye coleccion exportada en formato JSON.
